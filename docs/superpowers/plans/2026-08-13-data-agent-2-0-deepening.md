# Data Agent 2.0 深化实施计划

创建时间：2026-08-13 00:00:00

## 目标

在不引入 `sqlglot` 的前提下，把现有 Data Agent 从“可运行的 NL-to-SQL 原型”深化为“可治理、可学习、可解释、可度量、可消费”的轻量数据智能体系统。

## 范围

1. Semantic Layer 2.0：补齐指标版本、负责人、认证状态、时间维度、时间粒度、多指标计划、简单关系 Join 编译、歧义澄清。
2. Feedback 2.0：补齐错误原因枚举、 verified query 生命周期、从反馈生成语义模型更新建议，并让排序器使用 verified query 加分。
3. CandidateRanker 2.0：输出评分拆解、候选来源、选择理由、结果形状校验、语义计划匹配加分。
4. ResultAnalyzer 2.0：支持多行洞察、发现类型、Top K、比较、趋势、空结果、数据质量提示；为什么类问题必须返回限制。
5. Visualization 2.0：从推荐 spec 升级为可直接消费的 ECharts option，并支持图表字段校验和 finding 适配。
6. Evaluation Benchmark 2.0：新增 API 批量用例运行器、SQLite demo 数据构造、标签级指标、错误归因和 Markdown 报告。

## 非目标

- 不实现 SQL AST 级治理、策略引擎或复杂 join optimizer。
- 不自动修改语义模型文件，只产出建议。
- 不实现人工审核 UI。
- 不引入外部服务作为默认测试依赖。

## TDD 步骤

1. 先新增 2.0 测试，覆盖六个模块的关键行为，并运行确认失败。
2. 逐模块实现最小可用功能，保持既有 API 兼容。
3. 每完成一个模块运行对应测试。
4. 最后运行格式化、静态检查、全量测试和编译检查。

## 验收标准

- 新增 2.0 测试全部通过。
- 既有测试不回退。
- README 和项目说明反映当前实现。
- 生成带时间戳的迭代记录，包含效果、测试结果、风险和后续建议。
- 清理 `__pycache__` 等冗余产物，不引入无用代码。
